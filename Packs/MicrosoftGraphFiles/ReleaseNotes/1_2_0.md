
#### Integrations

##### O365 File Management (Onedrive/Sharepoint/Teams)

- Added a new command `***msgraph-driveitem-update***` to update properties (e.g. name, parent reference) of a drive item in OneDrive, SharePoint, or Teams.
- Added a new command `***msgraph-driveitem-copy***` to copy a drive item to a new location, with built-in monitoring of the asynchronous copy operation. On timeout the monitor URL is surfaced for retry under `MsGraphFiles.Copy.MonitorUrl`.
- Added a new command `***msgraph-driveitem-permissions-list***` to list per-driveItem sharing permissions, with `@odata.nextLink` pagination support via the `next_page_url` argument.
- Added a new command `***msgraph-driveitem-permission-delete***` to remove a specific permission (sharing entry) from a drive item, with an optional `ignore_not_found` argument for race-safe ForEach loops.
- Added a new optional argument `permanent_delete` to the `***msgraph-delete-file***` command to permanently delete a drive item (bypassing the recycle bin) when set to `true`. Existing recycle-bin behavior is preserved when the argument is omitted.
- Added new outputs under `MsGraphFiles.Remediation` to the `***msgraph-delete-file***` command for uniform downstream consumption. Existing outputs and behavior remain unchanged.
